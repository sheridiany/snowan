# 表格分析

目标:对用户的表格/数据(Excel、CSV)做**真实**分析或按模板**重排成新表**,结论先行;需要时用 `create_spreadsheet` 导出 Excel(每类别单独一个 sheet)或用 `matplotlib` 画图。**铁律:读全 → 建 → 回验,验过才交付。**

## 1. 读全(别用临时脚本/装包)
原件已存到 workspace 的 `uploads/`(附件块里标了路径)。**用 `read_table(uploads/…)` 把它读全**——它一次给出每个 sheet 的维度、合并区、逐行单元格值,以及**带公式单元格的公式原文**。
- 多 sheet 工作簿:`read_table` 默认列出所有 sheet;太大就 `sheet=` 逐页读。
- **先把结构搞清楚**:哪些指标在哪张表、列名是什么、占比/同比怎么算的(看公式),源表有没有错位/合并表头。
- 只有需要重统计(groupby/透视/大量计算)时才在 `execute_shell_command` 里用 python,且优先用 `read_table` 已给的数据,别再造读取脚本。

## 2. 建
- 按模板重排:用 `create_spreadsheet(title, sheets)`,每类别/科室**单独一个 sheet**(`name` 写类别名),`columns` 写表头,`rows` 写每行。
- **格式与口径对齐源表**:百分比指标把值写成 `"85%"` 这样带 % 的字符串;同比/占比算法跟源表一致(绝对量同比 = (本期−同期)/同期;占比/率的同比通常是**百分点差**,不是再除一次——以源表公式为准)。
- 模板里**每个核心指标都要有**;某科室某指标**源数据缺失就留空**,别填 0、更别瞎编。
- 图表(可选):`matplotlib` 画图 `savefig` 到 workspace,再 `present_artifact` 展示;只在能讲清一个发现时才画。

## 3. 回验(必做,别跳)
生成后**别直接说「完成」**:
1. **抽样核对**:用 `read_table` 读回你生成的文件,挑 2–3 个类别/科室,把算出来的值和**源数据逐项对比**,必须对得上。
2. **扫错误与异常**:有没有 `#DIV/0!`/`#VALUE!` 等错误、该留空处是否误填了 0、百分比是否漏 %、同比口径是否搞反。
3. **边界**:除数为 0 → 留空而非报错或 0;源缺数 → 留空;用公式的话确认重算后结果正确。
4. 发现问题就改,改完**重新读回再验**,直到零错误、抽样全对,才交付。

## 4. 报告(结论先行)
- 先给最重要的发现/结论(带具体数字),再给支撑细节;关键数据用 Markdown 表格。
- 交代**数据来源**(每个指标取自哪张源表/怎么算的)、做了哪些口径处理、哪些科室因缺数留空——像专业核数据的人那样说清楚,而不是只说「已生成」。
