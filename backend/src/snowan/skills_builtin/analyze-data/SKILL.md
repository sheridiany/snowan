# 表格分析

目标:对用户的表格/数据(Excel、CSV 等)做真实分析,给出**结论先行**的发现;需要时把结果导出成 **Excel**(用 `create_spreadsheet`)或图表。

## 拿到数据
用户上传/粘贴的表格**已经解析进对话**(在 `[附件 …]` 块里),**原件也已存到 workspace 的 `uploads/` 下**(块里标了路径)。所以:
- 数据就在眼前,**别让用户重新上传** —— 直接用对话里的内容做。
- 内容很大被预览截断、或要做精确透视时,可用 `read_file(uploads/…)` 读 CSV/文本原件,或在脚本里用 `pandas` 读 `uploads/` 下的原文件。
- 先确认列名和结构,搞清楚每个指标怎么算。

## 流程
1. **明确要什么**。汇总?趋势?对比?异常?还是按某模板**重排成新表**?不明确就按数据特征提 1–2 个最有价值的方向。
2. **算 + 整理**。需要统计就用 `pandas`(`describe`/`groupby`/透视/排序/过滤);只是按模板重排就直接读字段填表。数字要算出来,别「看起来大概是」。
3. **导出 Excel(常见诉求)**。要落成表格成果时用 `create_spreadsheet(title, sheets)`:
   - 每个类别/科室/分组**单独一个 sheet** → 一个 `sheet`,`name` 写类别名。
   - `columns` 写表头,`rows` 写每行单元格;**百分比指标把值写成 `"85%"` 这样带 % 的字符串**。
   - 生成后会**自动作为可下载成果**展示给用户,不用再 present。
4. **图表(可选)**。要图就用 `matplotlib` 画并 `savefig("chart.png")`(workspace 内),再 `present_artifact("chart.png", "…")` 展示。只在能讲清一个发现时才画。
5. **报告**。结论先行:先给最重要的发现(带具体数字),再给支撑细节;关键数据用 Markdown 表格呈现,并说明导出的文件里有什么。

## 质量底线
- 用真实数据,不要凭空编;数字要对得上原表。
- 结论先行 + 具体数字,别只描述方法。
- 按模板重排时,**模板里的每个核心指标都要有**,百分比记得加 `%`,缺的数据标注「无」而不是瞎填。
- 导出文件后确认生成成功;脚本报错就读错误、改了重跑,别把错误丢给用户。
