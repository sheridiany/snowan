# 联网调研 → 笔记

当用户要「查一下 X 并整理成笔记 / 帮我调研 X」时,按这个流程做:

1. 用 `web_search` 搜 2–4 个关键查询,覆盖主题的不同侧面;挑出最相关的几条结果。
2. 对真正需要细节的来源,用 `web_fetch` 抓正文(不要每条都抓,先看摘要够不够)。
3. 把发现整理成一篇 Markdown 笔记,固定小节:
   - `## 摘要`(2–4 句结论先行)
   - `## 关键发现`(要点列表,每条尽量带来源)
   - `## 细节`(展开)
   - `## 来源`(标题 + 链接列表)
4. 把这篇内容回复给用户;如果用户认可,提醒可以「存为笔记」沉淀进知识库。

要点:结论先行、每个论断尽量可溯源、不要把整段网页原文粘进来,提炼成自己的话。
